Arivu allows dynamically hot-swapping the inference engine resolving your schema mapping prompts. Through the dashboard or the Python SDK, you can select between leading Open Source and Proprietary models:

*   **OpenAI** (`gpt-4`, `gpt-3.5-turbo`)
*   **Anthropic** (`claude-3-opus`, `claude-sonnet`)
*   **Groq** (Hyper-fast specialized routing)
*   **DeepSeek** (Advanced code generation architectures)
*   **Ollama** (Local edge execution!)
*   **Alibaba Cloud** 

Use the settings panel to safely encrypt your API Keys locally.
