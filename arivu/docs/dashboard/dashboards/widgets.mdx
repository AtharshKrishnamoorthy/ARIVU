## Charts & Dashboard Items

Arivu dashboards currently support creating charts from saved queries and adding (pinning) those charts to dashboards. The supported, maintained features are:

- Dashboard creation and management (create, rename, delete)
- Create charts from saved queries
- Pin charts to dashboards
- Edit dashboard layout (drag & drop positioning)
- Manage charts (edit query, update visualization, remove)

## Creating a Chart and Adding to a Dashboard

<Steps>
  <Step title="Create a Chart">
    Save a query, choose a chart type (line, bar, pie), and configure axes and labels.
  </Step>
  <Step title="Pin to Dashboard">
    From the chart or query result view, click **Pin** and select the target dashboard.
  </Step>
  <Step title="Arrange Layout">
    Open the dashboard and drag the chart to the desired position. Save the layout.
  </Step>
</Steps>

## Managing Charts

- Edit a chart's underlying query or visualization settings from the chart detail view.
- Remove a pinned chart from a dashboard without deleting the underlying chart.
- Export chart data as CSV from the chart detail view.
