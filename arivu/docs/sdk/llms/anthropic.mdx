## Integration

You can assign Anthropic as your generation engine either by passing kwargs into the connection object or through environment variables.

<CodeGroup>
```python python
import os
from arivu import Arivu

os.environ["ANTHROPIC_API_KEY"] = "..."

db = Arivu.connect(
    # DB arguments...
    llm_provider="anthropic",
    model="claude-3-5-sonnet-20241022"
)
```
</CodeGroup>

<Note>
  Ensure your `arivu-ai[llm]` optional dependencies are installed via `pip install arivu-ai[anthropic]` if necessary.
</Note>
